# The Social Bond — GitHub Pages site

A responsive, original static-site rebuild inspired by the public information architecture and themes of thesocialbond.org. It includes local SVG artwork in `assets/`, so the visual assets are inside this ZIP and do not require external image hosting.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish on GitHub Pages
1. Create a GitHub repository and upload all files/folders from this ZIP.
2. Open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Wait for the Pages URL to appear.

## Before publishing
- This is an independent front-end concept, not the organization's official website.
- Confirm program details, statistics, address, phone numbers, and permissions before using them publicly.
- Donation and newsletter UI are intentionally not wired to payment or data collection. Connect an authorized provider before accepting donations or emails.
- Replace contact information or remove it if you do not have permission to publish it.
